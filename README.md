# Portafolio personal 

Mi sitio web de una sola página para presentar mi perfil, habilidades, proyectos y formas de contacto. Fue desarrollado como proyecto de práctica con HTML y CSS.


- Presentación personal
- Sección «Sobre mí»
- Habilidades
- Galería de proyectos
- Sección de contacto
- Diseño adaptable a distintos tamaños de pantalla
## Utilicé las tecnologías vistas en clase

- HTML 
- CSS
- Flexbox y Grid
- Media queries para diseño responsive

## Cómo ver el sitio

1. Descarga o clona este repositorio.
2. Abre la carpeta del proyecto en Visual Studio Code.
3. Abre `index.html` en un navegador. También puedes usar la extensión Live Server si la tienes instalada.

No se necesita instalar dependencias.
